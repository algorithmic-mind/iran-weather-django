# هوای من

یک برنامهٔ مینیمال جنگو برای نمایش وضعیت فعلی و پیش‌بینی سه روزهٔ آب‌وهوا با [Open-Meteo](https://open-meteo.com/en/docs). رابط فارسی و راست‌به‌چپ است و از Bootstrap 5، فونت وزیر و Bootstrap Icons استفاده می‌کند. فایل‌های ظاهری پروژه داخل `static/vendor/` قرار دارند و برای نمایش صفحه به CDN نیاز نیست. برای هر استان تصویر شاخص محلی نمایش داده می‌شود و همهٔ تاریخ‌های صفحه شمسی هستند. برای دریافت هوای زنده همچنان اتصال به Open-Meteo لازم است؛ شرایط استفاده از سرویس را در [صفحهٔ Open-Meteo](https://open-meteo.com/en/terms) ببینید.

## راه‌اندازی

پایتون 3.12 یا جدیدتر لازم است. در PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

سپس `http://127.0.0.1:8000/` را باز کنید. دستور `migrate` به طور خودکار ایران، ۳۱ استان، ۱۱۳۷ شهر/مکان و تصویر هر استان را در پایگاه‌داده ثبت می‌کند. انتخاب اولیهٔ فرم «ایران / البرز / کل استان» است. شهر دلخواه را می‌توان به صورت اختیاری انتخاب کرد. برای تغییر کشور یا استان، فرم به صورت خودکار ارسال می‌شود تا گزینه‌های وابسته به‌روز شوند؛ بدون جاوااسکریپت نیز دکمهٔ «نمایش هوا» کار می‌کند.

## راهنمای کد

برای آموزش قدم‌به‌قدم و توضیح جریان اجرای برنامه، [راهنمای آموزشی فارسی](docs/راهنمای-آموزشی.md) و [پاورپوینت آموزشی](docs/output/آموزش-پروژه-آب-و-هوا-نهایی.pptx) را ببینید.

| فایل | کار |
| --- | --- |
| `weather/models.py` | مدل‌های کشور، استان و شهر با مختصات؛ فیلد تصویر و انتساب آن در استان |
| `weather/migrations/0002_seed_iran.py` | وارد کردن دادهٔ اولیه هنگام مهاجرت |
| `weather/data/iran_locations.json` | دادهٔ استان‌ها و شهرها؛ [منبع و اصلاحات](weather/data/README.md) |
| `weather/data/photo_credits.json` | منبع، پدیدآورنده و مجوز عکس هر استان |
| `weather/data/province_captions.json` | توضیح کوتاهِ مکان یا منظرهٔ هر عکس |
| `media/provinces/` | فایل‌های محلی تصاویر شاخص استان‌ها |
| `weather/views.py` | اعتبارسنجی انتخاب‌ها و نمایش صفحه با یک view تابعی |
| `weather/services.py` | درخواست به Open-Meteo، تفسیر کد هوا و کش ۱۰ دقیقه‌ای |
| `weather/jalali.py` | تبدیل تاریخ میلادی پاسخ API به تاریخ شمسی با رقم فارسی |
| `templates/weather/home.html` | قالب راست‌به‌چپ و فرم انتخاب مکان |
| `static/weather/style.css` | ظاهر صفحه |
| `static/vendor/` | فایل‌های داخلی Bootstrap 5.3.8، Bootstrap Icons 1.13.2 و فونت وزیر 30.1.0 |

فرم با متد GET کار می‌کند. اگر شناسهٔ شهر به استان انتخابی یا شناسهٔ استان به کشور انتخابی تعلق نداشته باشد، view آن را نادیده می‌گیرد. در نبود شهر، مختصات استان برای هواشناسی به کار می‌رود. برای افزودن یا اصلاح مکان‌ها می‌توانید پنل مدیریت را فعال کنید:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

سپس به `/admin/` بروید. تصویر استان و توضیح کوتاه روی آن در پنل مدیریت قابل تغییر است. دادهٔ هوا از مسیر `/v1/forecast` سرویس Open-Meteo و با پارامترهای `current` و `daily` خوانده می‌شود. زمان‌ها با منطقهٔ زمانی `Asia/Tehran` درخواست می‌شوند و پیش از نمایش به شمسی تبدیل می‌شوند. در خطای شبکه یا سرویس، صفحه پیام مناسب نشان می‌دهد.

## اجرای آزمون‌ها

```powershell
.\.venv\Scripts\python.exe manage.py test
```

## تنظیمات اجرا

برای اجرای محلی، تنظیمات پیش‌فرض کافی‌اند. در استقرار واقعی، متغیرهای محیطی `DJANGO_SECRET_KEY`، `DJANGO_DEBUG=0` و `DJANGO_ALLOWED_HOSTS` را تنظیم کنید و فایل‌های static و media را از وب‌سرور ارائه دهید. تصاویر استان‌ها و همهٔ فایل‌های ظاهری محلی‌اند. روی هر تصویر، توضیح کوتاهی دربارهٔ مکان یا منظره نمایش داده می‌شود؛ انتساب عکس و لینک مجوز در پایین صفحه می‌آیند و اطلاعات کامل در [فهرست تصاویر](weather/data/photo_credits.json) ثبت شده‌اند. مجوزهای کتابخانه‌های ظاهری نیز در پوشه‌های مربوط در `static/vendor/` قرار دارند.

پاورقی صفحه امضای «طراحی و توسعه توسط [amirkho.ir](https://amirkho.ir/)» را نشان می‌دهد.
